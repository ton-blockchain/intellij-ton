Fills a struct initializer with the missing fields that have no default value.

Works like Fill all fields, but skips the fields the struct declaration already gives a default to, so only the ones that have to be written out are generated. It is offered only when that is actually a smaller set than all the missing fields.

Examples: 


struct Point {
    x: int
    y: int
    label: slice = createEmptySlice()
}

// Before
var p = Point {};

// After applying intention
var p = Point {
    x: 0,
    y: 0,
};

To use this intention, place your cursor on a struct initializer and press Alt+Enter.
