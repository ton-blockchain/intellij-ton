Fills a match expression with the arms it is still missing.

For a match over a union type an arm is generated for every variant that is not matched yet; for a match over an enum an arm is generated for every enum member. An else arm is appended unless the match already has one. Arms that are already present are left untouched.

The generated arms are placed where the caret stands when it is between the existing arms, and at the end of the match otherwise. A generated else always goes last, and no arm is ever placed below an existing else, since that would make it unreachable.

Examples: 


type Message = AskToTransfer | AskToBurn

// Before
match (msg) {
}

// After applying intention
match (msg) {
    AskToTransfer => {

    }
    AskToBurn => {

    }
    else => {

    }
}

To use this intention, place your cursor on a match expression and press Alt+Enter.
